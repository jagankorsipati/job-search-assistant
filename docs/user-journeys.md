# User Journeys

## 1. Establish my verified profile

The user creates an account, enters career facts, uploads a base résumé, reviews extracted facts, corrects them, and explicitly verifies each fact used for tailoring.

## 2. Save a job

The user pastes a job description or supplies a URL. The system captures available metadata, asks the user to correct missing fields, detects likely duplicates, and saves the job privately.

## 3. Understand my fit

The system separates requirements into matched, partially matched, unknown, and missing. Every match links to evidence in the verified profile. The user can correct the analysis without changing the underlying profile silently.

## 4. Tailor my résumé

The user requests suggestions. The system emphasizes relevant verified facts, identifies gaps separately, shows a before/after comparison, and exports only after approval.

## 5. Draft a cover letter

The system creates a draft grounded in the job and verified profile. Unsupported statements are blocked. The user edits and approves the result.

## 6. Track my application

The user moves the job through Saved, Evaluating, Preparing, Applied, Interviewing, Rejected, Withdrawn, or Offer. Every transition is recorded with time and optional notes.

## 7. Control my data

The user downloads their records and documents or deletes their workspace. Another household user cannot perform these actions for them unless a future delegated-access design explicitly permits it.
