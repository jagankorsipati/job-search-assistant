# User Journeys

## 1. Establish my owner-confirmed profile

An invited user creates an account, manually enters career facts, uploads a base resume, and explicitly confirms accurate facts. Upload does not extract facts. Confirmation is owner attestation, not independent verification.

## 2. Save a job

The user manually enters metadata and pastes a job description. A supplied URL is an inert reference, not a fetched page. The system warns about likely duplicates and saves immutable description snapshots privately.

## 3. Understand my fit

The user reviews requirements and explicitly links eligible candidate evidence. Deterministic analysis separates support, coverage, gaps and contradictions without silently changing profile facts or deciding qualification.

## 4. Tailor my résumé

The user manually authors a proposal pinned to the exact source resume ID/version/checksum and selects confirmed facts. Before/after wording approval does not authorize export. A separate actual-target review resolves a unique supported whole DOCX body paragraph; fresh target-bound attestation and a deliberate download request produce one separate ephemeral DOCX after final version checks. The source is unchanged. No suggestions are generated. Visual fidelity remains unverified; see [Phase 6 gates](security/phase-6-verification.md).

## 5. Draft a cover letter

Planned only: cover-letter drafting is not implemented. Phase 7 has not started.

## 6. Track my application

The user moves the job through Saved, Evaluating, Preparing, Applied, Interviewing, Rejected, Withdrawn, or Offer. Every transition is recorded with time and optional notes.

## 7. Control my data

Current owners can download their base resume and eligible single-proposal DOCX exports. General workspace export/deletion remains planned. Administrators cannot access another owner's documents. Proposal deletion is refused when decision history exists.
